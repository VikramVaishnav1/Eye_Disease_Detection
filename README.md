# Eye Disease Detection

This project builds a deep learning–based image classification model to detect common eye diseases from retinal images. [page:1] It uses Jupyter notebooks for data preprocessing, augmentation, model training, and evaluation. [page:1]

## Project Structure

- `Original Dataset/` – Raw retinal images organized by class (for example, normal vs diseased eyes). [page:1]  
- `Augmented Dataset/` – Expanded dataset generated by image augmentation to improve generalization. [page:1]  
- `models/tmpw5o78yfl/` – Saved model artifacts (weights/checkpoints) from training runs. [page:1]  
- `augment_images.ipynb` – Notebook to perform image augmentation and create the augmented dataset. [page:1]  
- `model.ipynb` – Notebook to define, train, and evaluate the eye disease detection model. [page:1]  

## Features

- End-to-end workflow in Jupyter Notebook (data loading, preprocessing, training, evaluation). [page:1]  
- Support for training on both original and augmented datasets. [page:1]  
- Saved model directory to reuse trained weights for inference or further fine-tuning. [page:1]
